# Projetos que foram identificados o uso de APIs

A tabela reune projetos que utilizam de diferentes APIs para funcionamento de aplicações que giram em torno da natureza gamer e também de crises climáticas.

<br>
<br>

| API | Frameworks/Tecnologias comuns | Tipo de dado | Autenticação | Nível gratuito |
|---|---|---|---|---|
| **PokéAPI** | JS/Fetch, React, Python, qualquer HTTP client | Pokémon, movimentos, tipos, evoluções | Nenhuma (pública) | Totalmente gratuita |
| **Xbox Live (OpenXBL)** | Node.js, Python | Perfis, conquistas, presença online | API Key (OpenXBL) | Sim, limitado |
| **PlayStation Network (psn-api)** | Node.js (biblioteca psn-api), Python | Troféus, biblioteca, perfis | Token NPSSO (login PSN) | Não oficial, uso pessoal |
| **Giant Bomb API** | JS/Fetch, Python | Wikis de jogos, personagens, vídeos/reviews | API Key | Sim, limitado |
| **Speedrun.com API** | JS/Fetch, Python | Recordes, categorias, leaderboards | Nenhuma (pública, algumas rotas com token) | Totalmente gratuita |
| **ClimateVision** | Python, Jupyter Notebooks | Modelagem de transição energética, análise de emissões de carbono | Nenhuma (Código aberto) | Totalmente gratuita |
| **h2oai-flood-intelligence-agent** | Python, H2O Wave, LLMs | Previsão de enchentes, análise geoespacial | API Key (para os modelos de IA) | Open source (APIs podem ter custos) |
| **OpenAthena-Legacy-Python** | Python | Geolocalização de alvos por imagens de drones e modelos de elevação (DEM) | Nenhuma (Execução local) | Totalmente gratuita |
| **WorldWind Wildfire** | JavaScript, HTML5, WebGL | Visualização 3D, monitoramento de incêndios florestais (dados FIRMS/NASA) | Nenhuma (Feeds públicos) | Totalmente gratuita |
| **Carbon Intensity API** | OpenAPI (YAML/JSON), Qualquer HTTP client | Dados e previsões de intensidade de carbono da rede elétrica do Reino Unido | Nenhuma (Pública) | Totalmente gratuita |
